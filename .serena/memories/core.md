# ORCA — core

Marine advisory reasoning system, SIH 2026 hackathon prototype (Team ICARUS).
Read `CLAUDE.md` (hard rules) and `TEAM_STATUS.md` (architecture decisions,
what's built) first — this memory does not repeat their content.

## Source map
- `orca/schema.py` — MarineObservation dataclass, the only type allowed to carry
  a number to a user. **Frozen once tests pass** (CLAUDE.md rule 5).
- `orca/policy.py` — safety decision engine (Finding/Decision/resolve). **Frozen
  once tests pass.** Zone-agnostic by design — see `mem:conventions`.
- `orca/agents.py` — 5 pure functions, list[MarineObservation] -> Finding.
- `orca/planner.py` — query -> agents over cached evidence -> policy.resolve()
  -> structured answer. Owns cross-zone comparison/alternative-search logic.
- `orca/api.py` — FastAPI (`/ask`, `/evidence/{id}`, `/health`).
- `orca/mcp_server.py` — same reasoning layer exposed as MCP tools.
- `data/fetch.py` — the ONLY file allowed to make network calls (CLAUDE.md
  rule 8). Writes real observations to `data/cache/*.json`.
- `web/index.html` — single-file frontend, no build step.
- `tests/` mirrors each module 1:1 (`test_<module>.py`); `tests/fixtures/`
  holds real captured API responses, not guessed shapes.
- `e2e/` — Playwright specs, run against real servers (`playwright.config.js`
  boots them).
- `demo/scenarios.json` — generated by `scripts/generate_demo_scenarios.py`
  from the real live API. Never hand-edit; never a hardcoded response path.

## Invariants
- No synthetic/mock/placeholder marine data anywhere, ever — not in
  `data/cache/`, not as an app fallback. Absent data -> logged + honest
  neutral result, never fabricated.
- `orca/schema.py` and `orca/policy.py` are safety-critical and frozen — see
  `mem:conventions` before touching either.
